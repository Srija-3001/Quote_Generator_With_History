# Quote Generator with History

## Description

A Flask web application that fetches random quotes from an external API and stores them in an SQLite database. The application also displays quote history.

## Features

* Fetch random quotes from API
* Store quotes in SQLite database
* Display quote history
* Dynamic quote generation
* Responsive user interface

## Technologies Used

* Python
* Flask
* SQLite
* Requests
* HTML
* CSS

## How to Run

Install dependencies

pip install flask requests

Run application

python app.py

Open browser

http://127.0.0.1:5000

## Project Structure

* app.py
* templates/index.html
* static/style.css
